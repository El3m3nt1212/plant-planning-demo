# Демо планирования производства

Публичная версия для GitHub Pages.

- `index.html` — простой недельный план (первый экран).
- `deep.html` — глубокая модель на 12 недель.
- Все данные синтетические. Это не данные завода и не коммерческое предложение.

## Как опубликовать

1. Создать на GitHub новый **публичный** репозиторий, например `plant-planning-demo`.
2. Загрузить в корень репозитория файлы `index.html`, `deep.html`, `.nojekyll` (и этот README).
3. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, Folder: `/ (root)`.
4. Через 1–2 минуты открыть `https://<username>.github.io/plant-planning-demo/`.
5. Проверить ссылку с телефона или из другой сети.
